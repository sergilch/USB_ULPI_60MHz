 Module lists per top were taken from the elaborated hierarchy

-------------------------------------------------------------------------------
 0. IMPORTANT: what "the digital portion" is today
-------------------------------------------------------------------------------
 There is no single top level yet that contains the whole digital design.
 The chip-level top usb_ulpi_phy_pads (-> usb_ulpi_phy_top) contains the ULPI
 core, register files, TX byte path and mode / termination control, but NOT
 yet (WORK_PLAN 8.1):
     usb_clk_gen, usb_rx_datapath, usb_afe_rx_if, usb_afe_tx_if8, usb_tx_piso,
     usb_pll_lock_det, usb_rx_status_sync, usb_line_state, usb_pwr_seq.
 These are synthesized as separate top levels (section 3).  Read the full RTL
 list of section 1 in every run; elaborate only the top you want.

 5. Constraints
-------------------------------------------------------------------------------
     constraints/usb_phy.sdc
         Clocks clk_bit 480 MHz, clk60 = clk_bit/8 (generated), clkout,
         clk_rx 480 MHz +1000 ppm, clk_rxw = clk_rx/8, ref_clk 24 MHz,
         virtual ulpi_clk; 60<->480 multicycles 4/3, async groups, ULPI and
         AFE I/O delays.  Placeholder pad / CDR delays (Plan_60MHz.md P9-O2).

     Notes for Genus (the SDC was written and checked with OpenSTA 3.1):
       * Its three tool-specific queries (port direction, driver pin of a net,
         driver cells of nets) are procs usb_port_is_input / usb_net_driver /
         usb_driver_cells that the SDC only defines if the caller has not.
         syn/genus_synth.tcl defines get_db versions before read_sdc.
       * It matches nets by name in a flattened design with "." as hierarchy
         separator (Yosys names): clk60, clkout, clk_rxw, rst_rx_m_n,
         rst_rx_m2_n, *u_piso.cq.  syn/genus_synth.tcl flattens with
         ungroup_separator "." before read_sdc and checks the clocks.
       * CKO_LEAD in the SDC must equal the usb_clk_gen parameter (default 2).

-------------------------------------------------------------------------------
 6. Settings the RTL relies on
-------------------------------------------------------------------------------
     * Verilog-2005, read with read_hdl (Verilog, e.g. -language v2001 or -sv).
     * Top-level parameters: keep the defaults (usb_ulpi_phy_pads: FS_DIV 40,
       LS_DIV 320, DIV_W 9, RX_DEPTH 8; usb_clk_gen: CKO_LEAD 2).
     * (* keep *) attributes on duplicated flops (reset copies, fan-out
       replicas in the clk_rx islands, CLAUDE.md "Reset") must be honoured:
       disable sequential merging for them (e.g. set_db optimize_merge_flops
       false, or preserve on those instances), otherwise the 2-cycle reset
       recovery copies collapse.
     * No latches are expected (run_synth.sh asserts none) - check
       check_design / report latches.
     * Reset: active-low asynchronous; scan insertion is not planned in the RTL.
