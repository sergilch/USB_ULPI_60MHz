# Discrete USB 2.0 receiver board (afe_receiver)

This is a prototype PCB of the PHY's receive front end: the HS receiver, the squelch detector and the HS disconnect detector. It implements the pins and behaviour of `AFE/veriloga/afe_receiver.va` (`RX_IN_P/N`, `RX_EN`, `RX_OUT_P/N`, `SQUELCH_A`, `DISC_A`). The board sits in the USB line (USB-B to the host, USB-A to the device, straight through) and taps D+/D− with two BFT92 emitter followers. An optional 45 Ω termination lets it act as the far end itself. The parts:

- SN65LVDS100 HS receiver (LVDS `RX_OUT`)
- TLV3603 window and envelope comparators for squelch / disconnect, with the thresholds from an MCP4822 DAC
- 74LVC1G00 / 1G08 gates for `RX_EN`

It is an FMC LPC mezzanine. An AMD 7-Series FPGA on the carrier oversamples `RX_OUT` at 1.92 GS/s (ISERDESE2) and `SQUELCH_A` / `DISC_A` at 960 MS/s into a triggered capture buffer. A PC script decodes the packets and the squelch timing.

Full description: [doc/rx_board.md](doc/rx_board.md) (Word: `doc/rx_board.docx`).

| Directory | Content |
|---|---|
| `easyeda/` | EasyEDA Std schematic (`usb_rx_board_sch.json`, 4 sheets), generated by `gen_schematic.py` from LCSC library parts (`lib/`); `netlist.csv` |
| `bom/` | BOM (`rx_board_bom.csv`) and JLCPCB assembly BOM (`rx_board_bom_jlcpcb.csv`) |
| `sim/` | ngspice characterisation of taps, HS receiver, squelch and disconnect (`run_sims.py`, models in `models/`, `usbpat.py` USB patterns, `tables.py`) |
| `fpga/` | FPGA design (`rtl/`), Icarus testbench (`sim/run_sim.sh`), XDC template, Vivado build script, Yosys check |
| `host/` | `rx_host.py` (UART: registers, capture, threshold sweep), `rx_decode.py` (CDR, NRZI, unstuffing, PID/CRC, squelch timing) |
| `doc/` | Documentation, figures (`gen_figures.py`), Markdown → Word converter (`md2docx.js`) |

```sh
cd easyeda && python3 gen_schematic.py              # schematic JSON, netlist, BOM
cd sim && JOBS=2 python3 run_sims.py                # all simulations (several hours on 2 cores); python3 tables.py
cd fpga/sim && ./run_sim.sh                         # FPGA testbench + decoder -> TEST PASSED
cd fpga && yosys -q -s synth_check.ys               # xc7 smoke synthesis
cd doc && python3 gen_figures.py && NODE_PATH=<npm dir>/node_modules node md2docx.js
```

To open the schematic in EasyEDA Std:

1. Open a new schematic.
2. Choose Design → *File Source* (the `<>` toolbar button).
3. Paste the contents of `easyeda/usb_rx_board_sch.json` and click **Create New Document**.

The four sheets open as one schematic.
