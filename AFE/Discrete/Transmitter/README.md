# Discrete USB 2.0 transmitter board (afe_transceiver TX)

This is a prototype PCB of the PHY's transmit front end: the HS current-steering driver, a fully discrete FS/LS driver (NX3008CBKS complementary pairs with Miller-capacitor slew control, comparator receivers), and the terminations/pulls. It implements the pins and behaviour of `AFE/veriloga/afe_transceiver.va`. The board is an FMC LPC mezzanine. An AMD 7-Series FPGA on the carrier runs the repo's TX RTL (`usb_tx_path` → `usb_afe_tx_if8`) and serializes it with OSERDESE2 at 480 Mbit/s.

Full description: [doc/tx_board.md](doc/tx_board.md) (Word: `doc/tx_board.docx`).

| Directory | Content |
|---|---|
| `easyeda/` | EasyEDA Std schematic (`usb_tx_board_sch.json`, 4 sheets), generated by `gen_schematic.py` from LCSC library parts (`lib/`); `netlist.csv` |
| `bom/` | BOM (`tx_board_bom.csv`) and JLCPCB assembly BOM (`tx_board_bom_jlcpcb.csv`) |
| `sim/` | ngspice characterisation of the HS driver (`run_sims.py`) and of the FS/LS driver (`run_fsls.py`); models in `models/`, `usbpat.py` USB patterns, `tables.py` |
| `fpga/` | FPGA design (`rtl/`), Icarus testbench (`sim/run_sim.sh`), XDC template, Vivado build script, Yosys check |
| `doc/` | Documentation, figures (`gen_figures.py`), Markdown → Word converter (`md2docx.js`) |

```sh
cd easyeda && python3 gen_schematic.py              # schematic JSON, netlist, BOM
cd sim && JOBS=2 python3 run_sims.py                # HS simulations (~1 h on 2 cores)
cd sim && JOBS=2 python3 run_fsls.py                # FS/LS simulations; python3 tables.py
cd fpga/sim && ./run_sim.sh                         # FPGA testbench -> TEST PASSED
cd fpga && yosys -q -s synth_check.ys               # xc7 smoke synthesis
cd doc && python3 gen_figures.py && NODE_PATH=<npm dir>/node_modules node md2docx.js
```

Opening the schematic in EasyEDA Std: open a new schematic, then Design → *File Source* (the `<>` toolbar button). Paste the contents of `easyeda/usb_tx_board_sch.json` and click **Create New Document**. The four sheets open as one schematic.

The symbols and footprints come from the JLCEDA/EasyEDA official library (https://easyeda.com, https://lceda.cn).
