# Discrete USB 2.0 PLL board (afe_pll)

This is a prototype PCB of the PHY's clock PLL: the lower loop of the PLL-assisted CDR block. It implements the pins and behaviour of `AFE/veriloga/afe_pll.va`:

- `CDR_FREF` (reference input)
- `PLL_EN`, `REFSEL1/0` (control)
- `CLK_BIT_A` (480 MHz) and `CLK60_A` (÷8) outputs
- `REF_DIG` (buffered reference)
- `CDR_CH_OUT_PLL` (control voltage)

The loop is built from standard parts:

- an ADF4002 phase-frequency detector with charge pump and R / N counters;
- the model's passive loop filter, C4 ∥ (R2 + C3);
- a discrete LC VCO: BFR93A Colpitts oscillator with a 1SV305 varactor, 378–516 MHz;
- a CDCM1804, which divides the VCO by 1 for CLK_BIT_A, by 8 for CLK60_A, and by 2 for the ADF4002 RF input.

The references are 24 MHz and 19.2 MHz oscillators, plus an SMA input for 26 MHz.

It is an FMC LPC mezzanine. An AMD 7-Series FPGA on the carrier runs the repo's own `usb_clk_gen` and `usb_pll_lock_det` RTL on the board's clocks, so it sees the board as the PHY core sees the integrated PLL. Around them the FPGA adds:

- a frequency counter;
- lock-time timers;
- a CLK60_A phase check;
- open-loop VCO tuning (DAC) and VTUNE read-back (ADC).

A PC script drives it over UART.

Simulated: lock to ±0.08 % in 12–15 µs over all VCO corners (spec 45 µs), PM ≈ 60°, reference spurs < −78 dBc. REFSEL 10 at 26 MHz (÷20) does not lock, as in the model.

| Directory | Content |
|---|---|
| `easyeda/` | EasyEDA Std schematic (`usb_pll_board_sch.json`, 4 sheets), generated by `gen_schematic.py` from `pll_parts.py` and LCSC library parts (`lib/`); `netlist.csv` |
| `bom/` | BOM (`pll_board_bom.csv`) and JLCPCB assembly BOM (`pll_board_bom_jlcpcb.csv`) |
| `sim/` | ngspice VCO (transistor level) and loop (XSPICE PFD / CP) simulations (`run_sims.py`, models in `models/`), `tables.py` (results, small-signal loop) |
| `fpga/` | FPGA design (`rtl/`), Icarus testbench with a board model (`sim/run_sim.sh`), XDC template, Vivado build script, Yosys check |
| `host/` | `pll_host.py` (UART: status, settings, lock-time statistics, open-loop VCO sweep) |
| `doc/` | Documentation, figures (`gen_figures.py`), Markdown → Word converter (`md2docx.js`) |

```sh
cd easyeda && python3 gen_schematic.py              # schematic JSON, netlist, BOM
cd sim && JOBS=3 python3 run_sims.py                # all simulations (~30 min on 3 cores); python3 tables.py
cd fpga/sim && ./run_sim.sh                         # FPGA testbench -> TEST PASSED
cd fpga && yosys -q -s synth_check.ys               # xc7 smoke synthesis
cd doc && python3 gen_figures.py && NODE_PATH=<npm dir>/node_modules node md2docx.js
```

To open the schematic in EasyEDA Std:

1. Open a new schematic.
2. Choose Design → *File Source* (the `<>` toolbar button).
3. Paste the contents of `easyeda/usb_pll_board_sch.json` and click **Create New Document**.

The four sheets open as one schematic.
